# Meteo Calculator

Отдельный репозиторий для курса "Базы данных (продвинутый уровень)"

## Описание проекта

Программно-аппаратный комплекс (ПАК) для автоматизации расчётных задач поддержки артиллерии в рамках Гособоронзаказа.

Система предназначена для регулярного измерения метеорологических характеристик на различных участках фронта и составления приближённого метеобюллетеня («Метео-11») на основе наземных измерений.


## Запуск проекта

1. Склонируйте репозиторий:
   ```
   git clone https://github.com/devstarash/meteo-calculator.git
   cd meteo-calculator
   ```

2. Перейдите в каталог `infra` и скопируйте пример конфигурации:
   ```
   cd ./infra
   mv env.example .env
   ```

3. Заполните `.env` своими значениями (пароли, порты, имя БД и т.д.)

4. Запустите Docker:
   ```
   docker compose up -d
   ```


> Файл `.env` содержит приватные данные и не должен попадать в git. Он добавлен в `.gitignore`.
